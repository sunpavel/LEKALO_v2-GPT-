# LEKALO: заявки на Vercel

Timeweb сохраняет заявку локально и отправляет её в serverless-функцию `api/leads.js` на Vercel. Функция доставляет уведомление в Telegram. Такой маршрут используется потому, что исходящие подключения Timeweb к `api.telegram.org` завершаются таймаутом.

## Переменные окружения

В Vercel откройте **Project → Settings → Environment Variables** и добавьте для окружения **Production**:

- `TELEGRAM_BOT_TOKEN` — токен бота;
- `TELEGRAM_CHAT_IDS` — один `chat_id` или несколько идентификаторов через запятую.

После добавления переменных выполните новый production deploy. Значения нельзя хранить в GitHub или вставлять в исходный код.

Timeweb по умолчанию использует `https://lekalo-v2-gpt.vercel.app/api/leads`. При смене домена Vercel задайте на Timeweb переменную `LEADS_RELAY_URL` с новым адресом. Значение `direct` отключает релей и включает прямое обращение к Telegram.

## Проверка

1. Открыть `/kontakty/`.
2. Заполнить тестовую заявку и отметить согласие.
3. Убедиться, что функция `/api/leads` вернула `200` и сообщение появилось в Telegram.
4. Проверить событие `generate_lead` в GA4 и цель `lead_submit` в Яндекс.Метрике.

На Vercel локальная файловая система функции не является постоянным хранилищем. Поэтому успешный ответ пользователю возвращается только после подтверждённой доставки хотя бы в один Telegram-чат.
